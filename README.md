# Mod Screen Manager

Автономная версия менеджера интерфейса для модов на «Бесконечное лето».

## Установка

1. Скопируйте `MSM.rpy` в папку своего мода.
2. Скопируйте `MSM_screens.rpy` туда же.
3. **Замените все вхождения `my_mod` в содержимом обоих файлов** на уникальный префикс своего мода.
4. Настройте словарь `my_mod_msm_config` в начале менеджера и замените примеры экранов своими.

### Вход и выход из мода

#### Вход

Готовый необязательный пример регистрации в `mods` и лейблов находится в
`example/my_mod_demo.rpy.example`.

#### Выход

Выключайте интерфейс при завершении истории. В примере кнопка «Главное меню»
показывает отдельное окно подтверждения. При подтверждении интерфейс
выключается перед возвратом в главное меню с помощью экрана `my_mod_exit_confirm`.

```renpy
textbutton "Главное меню" action Show("my_mod_exit_confirm")
```

Так вы выключаете интерфейс при выходе из вашего мода.

## Настройка и функции

Все глобальные переменные, функции, и прочие штуки менеджера
имеют префикс `my_mod_msm_`. Экраны имеют префикс `my_mod_`.

В `my_mod_msm_config` доступны:

| Параметр | Назначение |
| --- | --- |
| `MOD_NAME` | Имя мода без текстовых тегов |
| `MOD_ID` | Префикс экранов, совпадающий с префиксом после замены `my_mod` |
| `MOD_SAVE_IDENTIFIER` | Уникальная непустая метка в `save_name` для старых сейвов |
| `DEFAULT_SCREENS` | Имена стандартных экранов, которые требуется заменить |
| `MOD_REPLACE_WINDOW_NAME` | Менять ли заголовок окна на `MOD_NAME` (`True`/`False`) |
| `MOD_CURSOR_PATH` | Путь к курсору или `False` |
| `MOD_MENU_MUSIC` | Путь к музыке главного меню или `False` |
| `LOGGING`, `LOG_LEVEL` | Логирование в `log.txt` |

`MOD_CURSOR_PATH` задаёт аппаратный курсор Ren'Py. Hotspot находится в левом
верхнем углу, изображение до 32×32 пикселей поддерживается везде.

Пример содержит `game_menu_selector`, `say`, `choice`, `save`,
`load`, `preferences`, `skip_indicator` и опциональный `my_mod_file_slots` для кастомизации слотов сейва/загрузки для мода.
Для остальных экранов добавьте имя в `DEFAULT_SCREENS` по шаблону
`screen my_mod_<имя>`, сохранив параметры и обязательные widget id оригинала.

`game_menu_selector` обязателен и в конфигурации, и в файле экранов:
без него включение отменяется. Он автоматически добавляется при частичной
замене, отключить только его при активных остальных экранах **нельзя**.

```renpy
# Полная замена согласно конфигурации.
$ my_mod_msm_activate_screens()
# Добавить экраны к уже включённым.
$ my_mod_msm_activate_screens(["say", "choice"], partial=True)
# Заменить текущие экраны указанным (+ game_menu_selector).
$ my_mod_msm_activate_screens(["say"])
# Вернуть отдельный экран.
$ my_mod_msm_deactivate_screens(["say"])
# Вернуть весь интерфейс.
$ my_mod_msm_deactivate_screens()
# Переключение возвращает фактическое состояние указанного экрана.
$ my_mod_msm_toggle_screen("say")
$ my_mod_debug_status = my_mod_msm_get_status()
```

Новые сейвы сохраняют точный набор включённых экранов, включая частичную
замену и отключённый интерфейс. Для старых сейвов используется поиск непустых
`MOD_SAVE_IDENTIFIER` / `MOD_NAME` в `save_name`.

## Если влом тестить работу руками

Для проверки работы MSM движком создайте отдельный тестовый модик, положите
оба основных `.rpy`, рядом добавьте их копии с заменой `my_mod`
на `beta` (для второй копии задайте отличающееся `MOD_NAME`), затем добавьте
`tests/renpy_smoke.rpy.example` как `smoke.rpy`. Попробуйте запустить БЛ: при успехе в `log.txt` будут `MSM ENGINE SMOKE: OK` и
`MSM ENGINE SAVE/LOAD: OK`, `MSM ENGINE ROLLBACK: OK`.
